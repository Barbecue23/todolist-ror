# FORGE

Todolist ที่ออกแบบให้โฟกัส — Ruby on Rails 8 + Hotwire + Tailwind

## รันโปรเจ็ค

```bash
cd forge
bin/rails db:seed   # โหลดงานตัวอย่าง (ถ้าต้องการ)
bin/dev
```

เปิดเบราว์เซอร์ที่ [http://localhost:3000](http://localhost:3000)

## ความสามารถ

- เพิ่ม / ติ๊กเสร็จ / ลบงาน แบบ realtime (Turbo Streams)
- กรอง: ทั้งหมด / ค้างอยู่ / เสร็จแล้ว
- ระดับความสำคัญ: สูง / กลาง / ต่ำ
- แถบความคืบหน้าพร้อม animation
- UI บรรยากาศ cinematic พร้อม motion
